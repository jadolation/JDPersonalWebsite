🛠️ Common Issues & Fixes

Theme doesn't change when clicking heart button

Check: Browser console for errors, make sure romantic-content.js is loading

Love letters don't save

Check: localStorage is enabled (disable private browsing mode)

Password doesn't work

Check: Password in love-letters.js matches what you're typing (case-sensitive)

Content doesn't update

Check: Clear browser cache, verify romantic-content.js syntax
