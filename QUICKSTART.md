# 🚀 Quick Start Guide (5 Minutes)

## 1. Change the Password (30 seconds)
Open `love-letters.js`, line 2:
```javascript
const AUTHOR_PASSWORD = "your_secret_password_here";
```

## 2. Test Locally (2 minutes)
1. Open `index.html` in browser
2. Scroll down → Click heart button 💗
3. Watch theme change to pink/romantic
4. Click "Love Letters" in nav
5. Write a test letter using your password

## 3. Customize Content (2 minutes) - Optional
Edit `romantic-content.js`:
- Change hero title/subtitle
- Adjust her interests (dogs, anime, etc.)
- Personalize messages

## 4. Deploy (30 seconds)
```bash
git add .
git commit -m "Add romantic theme"
git push origin main
```

Enable GitHub Pages in repo settings → Done! ✅

## 🎯 That's It!

Visit your site:
- **Default view:** Professional tech portfolio (blue)
- **Click heart button:** Romantic surprise (pink) 💕
- **Love Letters page:** Write private messages for her

## 💡 Quick Tips
- Write 2-3 letters before showing her
- Password is case-sensitive
- Letters save in browser localStorage
- Theme choice persists across visits
