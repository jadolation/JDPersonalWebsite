# Personal Portfolio Website

A modern, responsive personal portfolio website for showcasing your skills, projects, and contact information.

## 🚀 Features

- **Responsive Design** - Works perfectly on all devices (desktop, tablet, mobile)
- **Smooth Animations** - AOS (Animate On Scroll) library for smooth scroll animations
- **Typing Effect** - Dynamic typing animation in the hero section
- **Modern UI** - Clean and professional dark theme design
- **Interactive Elements** - Hover effects, smooth transitions, and interactive cards
- **Contact Form** - Built-in contact form (ready for backend integration)
- **Social Links** - Quick access to your social media profiles
- **Smooth Scrolling** - Navigation with smooth scroll behavior
- **Mobile Menu** - Responsive hamburger menu for mobile devices

## 📋 Sections

1. **Hero/Home** - Eye-catching introduction with typing animation
2. **About** - Personal information and background
3. **Skills** - Technology stack and competencies
4. **Projects** - Showcase of your work and projects
5. **Contact** - Get in touch form and contact information

## 🛠️ Technologies Used

- **HTML5** - Semantic markup
- **CSS3** - Modern styling with custom properties, flexbox, and grid
- **JavaScript** - Vanilla JS for interactivity
- **Font Awesome** - Icons library
- **Google Fonts** - Poppins font family
- **AOS Library** - Scroll animations

## 📦 Getting Started

1. **Download/Clone** the files to your computer
2. **Edit the content** in `index.html`:
   - Replace "Your Name" with your actual name
   - Update email, phone, and location
   - Add your social media links
   - Replace placeholder images with your own
   - Update skills, projects, and about section
3. **Customize colors** in `styles.css`:
   - Edit CSS variables at the top of the file
   - Change `--primary-color`, `--secondary-color`, etc.
4. **Open** `index.html` in your browser

## 🎨 Customization

### Colors
Edit the CSS variables in `styles.css`:
```css
:root {
    --primary-color: #00d4ff;
    --secondary-color: #0099ff;
    --accent-color: #00ff88;
    /* ... more colors */
}
```

### Typing Animation
Change the phrases in `script.js`:
```javascript
const phrases = [
    'IT Student',
    'Web Developer',
    
];
```

### Images
Replace placeholder images:
- Profile picture: Update the `src` in the About section
- Project images: Update the `src` in the Projects section
