# Deployed project logos

Put one logo per project. SVG is preferred.

If you use PNG or WebP, make it at least 300px wide and ensure it reads on a light
background because the selector strip uses a light plate.

## Finishing a project
- Replace the image path and text in `main-page/index.html`.
- Set the real `href` on the button.
- Delete `data-placeholder` and `aria-disabled`.
- Delete the `<!-- OWNER: ... -->` comments you filled in.
